# מאגר השאלות

קובץ לכל רמה: `level-01.json` (הכי קל) עד `level-10.json` (הכי קשה). היעד הוא 100 שאלות בכל רמה, והמאגר אמור להמשיך לגדול.

## מבנה שאלה

```json
{
  "id": "L04-007",
  "cat": "תנ\"ך",
  "q": "על איזה הר, לפי המסורת, קיבל משה את התורה?",
  "options": ["הר סיני", "הר ציון", "הר נבו", "הר תבור"],
  "answer": 0,
  "explain": "הסבר קצר שמוצג מיד אחרי התשובה (אפשר להשאיר ריק)",
  "expansion": "פסקה של 2–4 משפטים עם עוד מידע על הנושא"
}
```

- `id`: `L` + מספר רמה בשתי ספרות + מספר רץ. לא משנים מזהה של שאלה קיימת.
- `options`: ארבע תשובות בדיוק. נהוג לשים את הנכונה ראשונה (`answer: 0`). המשחק מערבב את הסדר.
- `expansion`: בהמשך ישמש לשאלות המשך ולשאלות שבודקות אם השחקן קרא את ההרחבה. כל עובדה בהרחבה צריכה להיות בדוקה, כי ייתכן שתהפוך לשאלה.

## שאלות המשך

לכל שאלה רגילה יש שאלת המשך שנבנתה מההרחבה שלה. מזהה שאלת ההמשך הוא מזהה השאלה הרגילה עם `-F1` בסוף, והשדה `parent` מצביע על השאלה הרגילה. שאלת המשך יכולה להופיע במשחק רק אחרי שההרחבה של השאלה הרגילה כבר הוצגה, ולפחות 10 תורות אחריה.

## סגנון

השאלות צריכות להפתיע בלי להיות אזוטריות. טובה במיוחד שאלה שנשענת על משהו שכולם מכירים ומוסיפה לו פרט מפתיע: מי נחת עם ניל ארמסטרונג, או העובדה שויואלדי היה כומר. כדאי להימנע מפרטים שרק מומחה יודע.

## הוספת שאלות

מוסיפים שאלות בעזרת הכלי [tools/bank.js](../tools/bank.js), שקובע את המזהים לבד ובודק כפילויות:

```
node tools/bank.js stats                  # כמה שאלות יש בכל רמה
node tools/bank.js add batch.json         # הוספת מנה חדשה
node tools/bank.js followups map.json     # שכתוב של שאלות המשך קיימות
```

כל פריט במנה כולל `level`, `cat`, `q`, `options`, `explain`, `expansion` ושדה `followup` עם `q`, `options` ו-`explain`. תשובה נכונה תמיד ראשונה. כדאי לפזר את השאלות בין הקטגוריות.
