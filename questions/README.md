# מאגר השאלות

קובץ לכל רמה: `level-01.json` (הכי קל) עד `level-10.json` (הכי קשה). היעד הוא 100 שאלות בכל רמה, והמאגר אמור להמשיך לגדול.

## מבנה שאלה

```json
{
  "id": "L04-007",
  "cat": "תנ\"ך",
  "q": "על איזה הר, לפי המסורת, קיבל משה את התורה?",
  "options": ["הר סיני", "הר ציון", "הר נבו", "הר תבור"],
  "answer": 0,
  "explain": "הסבר קצר שמוצג מיד אחרי התשובה (אפשר להשאיר ריק)",
  "expansion": "פסקה של 2–4 משפטים עם עוד מידע על הנושא"
}
```

- `id`: `L` + מספר רמה בשתי ספרות + מספר רץ. לא משנים מזהה של שאלה קיימת.
- `options`: ארבע תשובות בדיוק. נהוג לשים את הנכונה ראשונה (`answer: 0`). המשחק מערבב את הסדר.
- `expansion`: בהמשך ישמש לשאלות המשך ולשאלות שבודקות אם השחקן קרא את ההרחבה. כל עובדה בהרחבה צריכה להיות בדוקה, כי ייתכן שתהפוך לשאלה.

## הוספת שאלות

מוסיפים לסוף הקובץ של הרמה, עם המספר הרץ הבא. כדאי לפזר את השאלות בין הקטגוריות ולהימנע מכפילויות עם שאלות קיימות.
