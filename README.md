# MyGames

## מי מכיר?

אפליקציית משחק ניחושים משפחתי. מחבר אחד בונה חידון קצר על עצמו, ה-AI מייצר את
התשובות השגויות (מסיחים), שאר המשפחה מנחשת בטלפון שלה, ובסוף חושפים מי מכיר הכי טוב.

- **קונספט:** [docs/concept.md](docs/concept.md) · דף מעוצב: [docs/concept.html](docs/concept.html)
- **סטטוס:** רעיון בשלב מוקדם. השלב הבא — אב-טיפוס דק של הזרימה המלאה.
